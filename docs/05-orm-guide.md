# 🗃️ Work with the async ORM

**Rusjango 0.1.4 · Alpha**

The ORM provides async create, read, update, and delete operations for SQLite and PostgreSQL.

This guide continues with the `school` app from [Applications](13-applications.md). Keep its starter API untouched if you want the automatic ORM upgrade.

## ⚙️ Enable SQLite

Stop the server, then run:

```bash
uv run rusjango add orm
uv run rusjango migrate
```

The CLI configures SQLite and adds missing starter files:

```text
demo/
├── settings.py
├── migrations/
│   └── .gitkeep
└── apps/
    └── school/
        ├── api.py
        ├── models.py
        └── schemas.py
```

> 💡 **What migrate does:** It creates missing model tables with `CREATE TABLE IF NOT EXISTS`. The `migrations/` directory is a scaffold placeholder; there are no tracked migration files or schema-alteration operations yet.

The generated `DATABASE` setting uses `db.sqlite3`. Server startup never creates tables automatically.

## 🧱 Define a model

The generated `apps/school/models.py` contains:

```python
from rusjango.orm import Integer, Model, String


class Student(Model):
    id = Integer(primary_key=True)
    name = String(max_length=100)
    age = Integer(nullable=True)
```

| Field | Stores |
|---|---|
| `Integer` | Integers; supports generated integer primary keys |
| `String` | Text with an optional declared maximum length |
| `Text` | Text |
| `Boolean` | Boolean values |

Fields support `primary_key`, `nullable`, `unique`, and `default`. Defaults are applied by `create`; callable defaults run for each insert. SQLite does not enforce VARCHAR length.

Declare the primary key explicitly. The ORM does not inject an `id` field.

## 📥 Try the generated API

```bash
uv run rusjango dev
```

Create a student:

```bash
curl -X POST http://127.0.0.1:8000/api/school/students \
  -H "Content-Type: application/json" -d '{"name":"Ali"}'
```

For a fresh database, the response has this shape:

```json
{"id": 1, "name": "Ali", "age": null}
```

The ID is generated by the database. Existing rows can make the returned ID different.

List students:

```bash
curl http://127.0.0.1:8000/api/school/students
```

If you customized the starter API before enabling ORM, the CLI preserves it. Add ORM calls to your handlers yourself.

## ✍️ Use CRUD in Python

Here is an async helper you can call from a handler or another async function:

```python
from apps.school.models import Student


async def demonstrate_crud():
    student = await Student.create(name="Sara", age=22)

    saved = await Student.get(id=student.id)
    matching = await Student.filter(age__gte=18).all()
    first = await Student.filter(name="Sara").first()

    changed = await Student.filter(id=student.id).update(age=23)
    deleted = await Student.filter(id=student.id).delete()

    return {
        "saved": saved.to_dict(),
        "matching": [item.to_dict() for item in matching],
        "first": first.to_dict() if first else None,
        "changed": changed,
        "deleted": deleted,
    }
```

`update` and `delete` return actual affected-row counts. Both require at least one filter.

| Operation | Result |
|---|---|
| `Student.create(...)` | Inserted model instance |
| `Student.all()` | List of model instances |
| `Student.get(...)` | One instance, or an exception |
| `Student.filter(...).all()` | All matching instances |
| `Student.filter(...).first()` | First match, or `None` |
| `Student.filter(...).update(...)` | Number of changed rows |
| `Student.filter(...).delete()` | Number of deleted rows |

Results have no guaranteed ordering.

### Filter lookups

| Lookup | Meaning |
|---|---|
| `name="Ali"` or `name__exact="Ali"` | Equal |
| `age__gt=18` / `age__gte=18` | Greater than / at least |
| `age__lt=30` / `age__lte=30` | Less than / at most |
| `age=None` | SQL `IS NULL` |

Filters can be chained. Unknown field names are rejected.

### Handle a missing row

```python
from rusjango import HTTPException
from rusjango.orm import DoesNotExist


async def require_student(student_id: int):
    try:
        return await Student.get(id=student_id)
    except DoesNotExist:
        raise HTTPException(404, detail="Student not found")
```

`get` raises `MultipleObjectsReturned` when more than one row matches. Both ORM exceptions are available from `rusjango.orm`.

## 🐘 Use PostgreSQL

Install the optional driver into the project environment:

```bash
uv add "rusjango[postgres]==0.1.4"
```

Then replace `DATABASE` in `settings.py`:

```python
DATABASE = {
    "ENGINE": "postgresql",
    "URL": "postgresql://user:password@localhost:5432/demo",
    "MIN_SIZE": 1,
    "MAX_SIZE": 10,
}
```

Use credentials for a database you control, then run `uv run rusjango migrate`. Changing the setting does not copy SQLite data to PostgreSQL.

`postgres` is an engine alias. You may use `DSN` instead of `URL`. Pool connections are returned after operations, including errors.

## 🏷️ Table names and lifecycle

App models default to `<app>_<class_lowercase>`; the generated Student uses `school_student`. Other models use the lowercased class name. Set `_table` on a model to override its name.

There is one database configuration per process. Connections open lazily and close during ASGI shutdown. Standalone async scripts should call `await close_db()` in a `finally` block. Close an active database before reconfiguring it.

## 🧭 Current limits

SQLite requires **3.35+** for `INSERT ... RETURNING`. Schema validation is separate from ORM/database constraints.

Transactions, relationships, tracked migrations, ordering, pagination, joins, and a count API are pending.

> 📌 **Existing database upgrade:** Older versions could store models in a table named `model`. Back up and inspect those rows, then move them with explicit SQL. Corrected table names do not rename tables or migrate data automatically.
